# 基金篮子

顶栏篮子连接六个页面。电脑从右侧展开，宽度不超过 768px 时从顶部展开；NAV 全屏时入口留在右下方。

## 使用

- 基金列表单击单选，Ctrl（Mac 用 ⌘）点击追加/取消，Shift 点击选择当前页连续区间，Ctrl/⌘＋Shift 追加区间；触屏点按仍逐只切换多选。翻页保留已选基金，翻页/排序/筛选后重置区间起点，待补全行跳过。也可点击详情表格列多选；篮子高亮后点击入口，使用“加入篮子”。计算器和 NAV 也可一次收集当前页面的基金。
- 计算器环绕画廊通过独立把手拖动基金，正文用于转动画廊；其他列表鼠标可拖动基金行/列，手机从 `⠿` 把手起拖，正文继续正常滚动。页面拖出高亮篮子并显示直径 260px 的虚线接收圈（原为 130px），单只基金另高亮“基金详情”顶栏；不显示整页添加/替换遮罩。
- 拖动顶栏篮子使用整篮；展开后拖动某只基金使用单只，勾选后拖动已勾选行或“拖出所选”使用多选。
- 计算器和净值比较显示“添加 / 替换”两区，位于篮子浮窗下方。添加去重并保留当前基金，替换保留页面设置及 NAV 比较基准。篮子中的基金不会被消费或删除。
- 基金详情页支持篮子单只拖入直接打开；整篮或所选多只拖入时，页面显示该批基金列表，指向某行高亮、松开打开该只。列表边缘自动滚动，浮窗保持在上层；窄屏把选择区排在篮子浮窗下方。浮窗的“查看基金详情”按钮也可进入选择。
- 拖动任意来源的单只基金时，“基金详情”顶栏边框高亮，松开即跳转到对应代码；窄屏自动露出该标签，和扩大后的篮子接收圈重叠时优先识别详情标签。多只拖动仍可停留在目标顶栏约 600ms 切页，再选择落点。
- 点击把手可进入操作状态，再点击接收区；浮窗还提供添加/替换按钮。Esc、取消、松开到区域之外都不会应用操作。
- 支持全选、移除所选、单只移除和清空。本机同源 localStorage 保存并同步其他标签页，浏览器禁止存储时仅本次会话有效。

## 模块与契约

| 模块 | 职责 |
| --- | --- |
| `js/data/basket-store.js` | `{v:1,items:[{code,name}]}`；六位基金代码校验、按插入顺序去重、200 只容量、存储与同步 |
| `js/core/fund-drop.js` | 共享接收圈直径与命中检测、详情落点代码与拖动快照校验 |
| `js/core/fund-transfer.js` | 页面来源/接收器注册、选中项通知、转义拖动属性、有限并发数据准备 |
| `js/components/fund-basket.js` | 全局浮窗、Pointer Events、键盘入口、目标区域、状态提示及 NAV 全屏入口 |
| `css/components/_fund-basket.css` | 顶栏、浮窗层级、桌面/手机布局及拖动反馈 |
| `js/pages/nav/basket-transfer.js` | NAV 添加/替换计划、去重、受保护基准和容量限制 |

页面接入使用 `fundDragAttrs(fund)` 和 `fundDragHandle()`；拖动属性只承载公开基金引用，名称必须经过属性转义。通过 `registerFundSource(key, route, getSelection, priority, explicitSelection)` 注册多选来源，并在变化后调用 `notifyFundSelection()`。显式表格多选优先于页面当前基金；`explicitSelection=false` 的来源供一键收集使用，不把单行拖动扩展成整页拖动。

接收页通过 `registerFundReceiver(route, async (items, mode) => count)` 注册。计算器/NAV 先准备并验证全部数据，再提交状态；加载失败、页面在等待期间变化、超过 NAV 10 项（含基准）时给出错误，保留原内容。篮子不传递自定义费用、持仓、指数或图表数据。计算器数据继续使用现有费用适配器，NAV 继续使用现有比较缓存。基金详情每次只接收一只，转入 `#/fund/<code>` 并复用详情加载与错误展示；多只必须先选行，不会静默选择第一只，也不会从篮子删除基金。

## 回归检查

1. 列表跨搜索/分页选择两只，点击收集，再拖入第三只；重复收集不增数。
2. 在计算器拖整篮添加；在篮子选两只并拖动替换；取消和失败时检查原卡片保留。
3. 在 NAV 拖整篮/单只添加替换，检查基准保留、基金去重和容量提示。
4. 确认页面→篮子无整页遮罩；篮子→页面浮窗位于遮罩上方且操作标题可见。
5. 测试键盘点击把手、Esc、窄屏触屏把手、普通滚动、深色、NAV 全屏、刷新与跨标签页同步。
6. 在详情页拖单只、整篮与所选多只，确认落点选择、长列表边缘滚动、手机浮窗与选择区分开，以及点击/键盘替代入口。
7. 从其他页面和篮子拖单只到详情顶栏（含详情页尚未加载、窄屏标签起初不可见）；在扩大接收圈的新增范围松开应加入篮子。检查 Esc/取消后松手不会重新起拖，单只接收区的取消按钮不会触发打开。
8. 延迟首次页面模块加载后快速切换路由，最后一个目标页及其篮子接收器应生效。

业务回归通过 `npm test` 执行；浏览器验证使用独立浏览器上下文和本机只读 API，不修改用户页面缓存或运行外部抓取。
