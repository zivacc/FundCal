# 前端布局、主题与篮子基金池审查（2026-09-28）

## 实现与复现修复

- 列表增加独立、可关闭的篮子基金池。服务端在搜索/过滤/计数/排序/分页前限制代码；包含待补全行，以 `.OF` 优先消除同代码多市场重复。真实篮子 4 个代码曾返回 5 行，修复后 4 行。空池和无效代码保持空，不扩大成全库；静态灾备使用相同限制。
- 浮窗与列表共享同一个篮子 store，不复制持久数组。拖入/按钮入口查看整篮，清除旧搜索与筛选；开关仅改变范围，后续可在池内筛选。刷新失败清空旧结果并显示错误，不用全库旧结果冒充新池；越界分页重新取最后一页。每页条数去掉超过服务端 500 上限的 1000 选项。
- 手机原始数据弹窗标题被顶栏遮挡、底部按钮横向截断：弹窗提高到独立上层，约束动态视口高度，内容单独滚动，头尾不压缩，操作按钮换行。390×844 下弹窗边界为 y=16–828。
- 桌面筛选栏收起状态污染手机抽屉：原宽度仅 36px，现仅桌面应用折叠样式；390px 视口下展开宽度 380px（含 10px 滚动条余量）。补充展开状态及 Escape 关闭；列表比较浮钮移到筛选按钮上方。
- 手机净值图例长名称被逐字挤成竖排：名称/代码及数值分两行，工具栏独占一行，保留颜色标识和全名提示。390px 下基金图例单行项高约 44px。
- 基金详情净值 canvas 未监听缩放：桌面切页后缩到 390px 再回来，曾保留 1196px 画布、使文档宽达 1233px。补 ResizeObserver/路由恢复与局部主题更新，修复后容器/画布均 306px、文档 380px。补净值请求版本检查，避免旧基金/旧区间响应覆盖新选择。
- 辅助文字、坐标及暗色净值曲线提高对比度；辅助文字在基础/卡片/次级/浮层背景至少 4.5:1，净值系列颜色至少 3:1，由测试约束。主题按钮统一为 40px 点击区域；窄屏按钮和辅助字避免过小；列表表头提升到 12px。详情负收益使用主题变量，不再固定浅色绿。
- 顶栏同步 `aria-selected`，切页/改宽度露出当前标签；详情搜索框铺满窄屏可用宽度。修正列表与统计页过时的数据托管提示。

## 验证范围

使用应用内浏览器、现有公开基金引用和本机服务；没有全量抓取、导入、静态重建或基金数据库写入，也没有增删用户篮子。

| 页面 | 核对内容 |
| --- | --- |
| 计算器 | 桌面多卡片、手机前排编辑区域、控件排列、图表容器；保留设计上的后排卡片叠放 |
| 基金列表 | 实际指针拖入、模式开关、4 只同代码去重、`jd` 池内搜索、晨星排序、筛选抽屉与 Escape、原始数据弹窗 |
| 指数选基 | 搜索区、既有指数结果、长名称表格及排序图、背景连续性 |
| 净值比较 | 长名称多基金图例、主副图、亮暗切换、手机全屏及退出、基准和工具条 |
| 统计 | 汇总/卡片、维度切换、手机基金明细抽屉及关闭 |
| 基金详情 | 基础/费率、晨星两图、原始数据、净值画布跨页缩放及主题更新 |

主要视觉检查为 1280×900 桌面与 390×844 手机视口，亮暗模式；另对六页执行 320px、768px 边界宽度 DOM 几何检查。修复后六页未出现文档级横向溢出；宽表保留容器内横向滚动。控制台未见本轮运行错误。检查不是所有浏览器、所有数据、所有交互组合的穷举，未进行真实手机触屏/软键盘、安全区或屏幕阅读器验收；公共 Tunnel/边缘缓存不在本次验证内。
