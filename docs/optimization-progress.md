## 第一批：缓存复用与请求正确性（2026-09-05）

已完成：

- **A04 缓存空值故障**：内存命中统一读取记录的 `body`；首次网络、持久缓存、304 校验和静态兜底的结果均可重复读取。
- **A05 查询解析与异常隔离**：基金和净值接口共用标准查询解析，正确处理空格、中文、加号和等号；错误百分号或 UTF-8 编码在访问路由和数据库前返回 400。HTTP 入口捕获同步异常和异步拒绝，返回不含内部异常详情的 500，并继续处理后续请求。
- **A18 无效索引请求**：指数索引改用 `/api/nav/index-search-index`；联接基金索引直接访问实际存在的静态构建产物，省去每次缓存过期后必然失败的 API 请求。
- HTTP server 可独立创建并注入测试路由；导入模块不再自动监听端口，测试不需要真实数据库或外部抓取。

验证：新增 20 项回归测试，全量 **251/251 通过**。本地 API 实际验证两种错误编码均返回 400，随后基金分页、净值范围、指数索引（159 条）与晨星查询返回 200，静态联接索引返回 200。本地 API 已重启加载修复。

本批没有关闭整个 A04/A05/A18 审计项：缓存离线有效期与 SWR 语义、NAV limit 下界及参数校验、API/静态 DTO 一致性仍待后续处理。本批不改变数据源裁决、数据库记录或部署访问策略。
