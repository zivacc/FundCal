# 代码优化执行记录

依据：[2026-09-05 审计](audits/2026-09-05/README.md)。账本移除后的基线提交为 `c0c812d`。每批完成回归验证并独立提交，原始审计证据保留为历史记录。

## 第一批：缓存复用与请求正确性（2026-09-05）

已完成：

- **A04 缓存空值故障**：内存命中统一读取记录的 `body`；首次网络、持久缓存、304 校验和静态兜底的结果均可重复读取。
- **A05 查询解析与异常隔离**：基金和净值接口共用标准查询解析，正确处理空格、中文、加号和等号；错误百分号或 UTF-8 编码在访问路由和数据库前返回 400。HTTP 入口捕获同步异常和异步拒绝，返回不含内部异常详情的 500，并继续处理后续请求。
- **A18 无效索引请求**：指数索引改用 `/api/nav/index-search-index`；联接基金索引直接访问实际存在的静态构建产物，省去每次缓存过期后必然失败的 API 请求。
- HTTP server 可独立创建并注入测试路由；导入模块不再自动监听端口，测试不需要真实数据库或外部抓取。

验证：新增 20 项回归测试，全量 **251/251 通过**。本地 API 实际验证两种错误编码均返回 400，随后基金分页、净值范围、指数索引（159 条）与晨星查询返回 200，静态联接索引返回 200。本地 API 已重启加载修复。

本批没有关闭整个 A04/A05/A18 审计项：缓存离线有效期与 SWR 语义、NAV limit 下界及参数校验、API/静态 DTO 一致性仍待后续处理。本批不改变数据源裁决、数据库记录或部署访问策略。

## 第二批：访问边界（2026-09-05）

- 静态服务改为内置资源白名单，拒绝目录浏览、路径穿越、非公开符号链接和仓库内部文件；`npm run dev` / `npm run serve` 均使用新入口。
- 静态与 API 默认只监听本机。抓取入口只接受本机直连，同时拒绝公网 Host、外站 Origin 和代理请求头；公共查询照常通过 Tunnel 使用。
- 同基金抓取合并，最多 2 个并发任务，超限返回 429；子进程错误、输出上限及超时清理集中处理。
- 回归覆盖静态 GET/HEAD/304、隐藏路径与符号链接、HTTP 403 和任务并发/失败释放。公网 Cloudflare 配置仍未审计。

验证：全量 256 项通过；实际服务 GET/HEAD 验证公共资源可用、数据库与源码 404、外站抓取 403。本批提交 `fed6366`。

## 第三批：搜索加载与列表查询（2026-09-05）

- 搜索索引按数据库版本缓存，启动预热，复用 JSON、ETag 和 gzip；传输从 2.33 MB 降至约 450 KB。
- 基金/指数搜索启用 SWR 和聚焦预加载，去掉会阻断缓存更新的页面副本；空搜索不再遍历索引。
- 列表搜索固定从匹配代码集合查已有代码索引；7 组正式库只读对照结果一致。
- 全量 260 项回归通过。本机 hs300 重复搜索由约 646 ms 降至 6.5–8.8 ms；首次仍约 75 ms。完整加载链路、测量条件和剩余问题见 [搜索分析](performance/search-loading.md)。

## NAV 全屏交互（2026-09-06）

- 全屏保留主图、副图、图上基准与选区操作，以及小型悬浮控制条；基金、区间、指标、统计、工具每次只展开一个面板。控制条可进一步收成“控制”按钮，退出入口保持可见。
- 宽屏使用右侧浮层；宽度不超过 768px 时使用底部面板和底部控制条，避免短横屏顶部控件相互覆盖。面板支持点击收起、点击图表收起及触屏下拉标题区收起；Esc 优先关闭搜索候选，再关闭面板、退出全屏。

- 新模块为 `js/pages/nav/fullscreen.js`，样式为 `css/pages/_nav-fullscreen.css`。面板开合不改变绘图区尺寸；手机底部预留控制条空间，短横屏收紧图间留白。
