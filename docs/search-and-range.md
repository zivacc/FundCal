# 搜索与区间调整

## 统一搜索

`js/utils/search.js` 是浏览器和服务端共用的匹配、排序入口。`filterSearchIndex(items, query, options)` 的 `kinds`、`predicate`、`limit` 仅控制范围及数量，不改变匹配规则。

- 代码/名称精确匹配 → 前缀 → 任意位置包含（含拼音首字母）→ 有序跳字 → 英文单字母增删改/相邻交换。
- 当前范围没有直接命中时才启用跳字和错字兜底，避免 `NDX` 等准确代码后面混入不相关的模糊结果。
- 支持空格分隔的多个关键词，要求全部匹配；大小写、全角及常见标点统一归一化。
- `jd` 可匹配 `dfhjddsjhha`（东方红京东大数据混合A）；`东方红 京东` 可组合检索。
- `NDX`、`SPX`、`HSI` 支持直接代码检索；常用指数别名也供只有跟踪标的名称的入口使用。别名只扩展检索，不创建缺失的指数数据。
- 短于三字符的词不跳字匹配；纯数字不进行错字纠正。混合代码不会被剥成数字，例如 `A500` 不会误当作 `500`。
- 搜索池条目按不可变对象使用，以便缓存标准化字段。更新名称/首字母时创建新对象。

计算器、卡片和基金详情搜索基金；净值比较搜索可用基金及指数；指数选基、选择弹窗和统计搜索跟踪标的；公司筛选只搜索公司。分页列表先用同一搜索引擎得到代码及相关性，再通过参数化 `json_each` 联结 SQL，最后应用筛选和分页。默认代码升序在搜索时按相关性排序，显式费率等排序仍然有效。

## 区间边界

净值图右键拖选后，左右虚线各有独立把手。拖动把手可修改对应日期，另一端保持不动；区间统计按帧更新，松手会提交最后一个坐标。边界不能互相穿过。

聚焦把手后可用左右方向键微调一个数据点，Shift + 方向键移动十个点，Home/End 移到允许的边界。图表获得焦点后 Shift + F10 可创建可调整区间，供不能右键拖动的键盘用户使用。原有顶部把手仍可整段平移。缩放后屏幕外的实际边界不显示把手，避免把裁剪边缘误当成真实端点。

区间统计允许选很短的区间；图表本身的最小缩放范围仍为 100 个数据点（总数不足则全部显示）。
